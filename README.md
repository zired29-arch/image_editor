# PhotoRedactor

Данное приложение служит для обработки фотографий в веб интерфейсе

## Технологии
* **Язык:** Python 3.13+
* **Фреймворк:** Flask
* **ORM:** Peewee
* **СУБД:** SQLite
* **Фронтенд:** HTML + CSS

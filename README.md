# PhotoRedactor

Данное приложение служит для обработки фотографий в веб интерфейсе

## Технологии
* **Язык:** Python 3.13+
* **Фреймворк:** Flask
* **ORM:** Peewee
* **СУБД:** SQLite
* **Фронтенд:** HTML + CSS

## Локальный запуск
1. Клонировать репозиторий  
   ```git clone [https://github.com/zired29-arch/image_editor](https://github.com/zired29-arch/image_editor.git)```
2. Установить вирутальное окружение  
   ```python -m venv .venv```
3. Активировать виртуальное окружение
   ```.venv/Scripts/activate```
4. Установить зависимости
    ```pip install -r requirements.txt```
5. Создать файл в корневой папке проекта с названием ```.env``` и заполнить данными:
   ```SECRET_KEY=<ключ приложения (можно сгенерировать любой случайной строкой)>
   MAILKEY=<ключ приложения от почты (яндекс)>
   EMAIL=<ваша почта (яндекс)>```
6. Запустить приложение командами:
   ```python main.py```
   ```python timer.py```
